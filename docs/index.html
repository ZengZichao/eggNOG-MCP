eggNOG-MCP

A Model Context Protocol server bridging the eggNOG 7 database with AI assistants — enabling natural-language access to orthology assignments and functional annotations for comparative genomics.

01Overview

eggNOG (evolutionary genealogy of genes: Non-supervised Orthologous Groups) is a database of orthology relationships, functional annotations, and phylogenetic trees. eggNOG-MCP implements the Model Context Protocol to expose this database to any MCP-compatible AI assistant.

12,000+
Annotated Species
59M+
Protein Sequences
3.1M+
Orthologous Groups

The server communicates with eggNOG's native JSON API (/e7api/) for reliable, structured data access — no HTML scraping required. Once configured, AI assistants such as Claude Desktop, Cursor, or custom agents can query eggNOG directly through natural language.

⚠️ Disclaimer: This is a community-maintained, unofficial MCP server. It is not affiliated with, endorsed by, or maintained by the eggNOG team or EMBL. The official eggNOG database is available at eggnogdb.org.

03Available Tools

Ten MCP tools provide comprehensive access to the eggNOG database, from protein lookups to functional annotation.

get_protein
Retrieve protein family, predicted functions, and orthologous groups for any eggNOG protein ID.
get_orthologous_group
Look up OG details: evolutionary origin, member counts, functional annotation, and family OG list.
get_og_content
List all proteins within an OG, grouped by species, with configurable result limits.
get_orthologs
Retrieve pairwise orthologs for a protein across all available species.
search_eggnog
Search by protein name, UniProt ID, or family name with autocomplete support.
annotate_protein
Get structured KEGG KO and GO term annotations with confidence scores.
get_protein_family
Browse all species and proteins within a protein family cluster.
get_database_stats
Access current eggNOG 7 release statistics — species, proteins, trees, and OG counts.
list_downloads
List all bulk-downloadable data files with URLs and descriptions.
get_taxid_info
Look up taxonomic information by NCBI taxonomy ID.

04Key Features

Designed for reliability and ease of integration in bioinformatics workflows.

✓ Native JSON API — Uses eggNOG's /e7api/ endpoints for structured data access, no HTML scraping.
✓ Async HTTP — Built on httpx for efficient non-blocking network requests.
✓ Functional Annotation — KEGG KO and GO terms returned with confidence scores.
✓ MCP Resources — Version info, database stats, and downloads exposed as MCP resources.
✓ Error Resilient — All tools return structured error messages instead of crashing.
✓ Cross-Platform — Works with Claude Desktop, Cursor IDE, or any MCP-compatible client.

05Quick Start

Install and run in two commands. Then configure your AI assistant to use it.

$ pip install eggnog-mcp $ eggnog-mcp

Or install from source for development:

$ git clone https://github.com/ZengZichao/eggNOG-MCP.git $ cd eggNOG-MCP $ pip install -e ".[dev]"

Configuration

Add the server to your MCP client configuration:

{ "mcpServers": { "eggnog-mcp": { "command": "eggnog-mcp", "args": [] } } }
{ "mcpServers": { "eggnog-mcp": { "command": "eggnog-mcp" } } }
{ "mcpServers": { "eggnog-mcp": { "command": "python", "args": ["-m", "eggnog_mcp.server"], "env": { "PYTHONPATH": "/path/to/eggNOG-MCP/src" } } } }

07MCP Resources

In addition to tools, the server exposes three read-only resources accessible via MCP resource URIs.

Resource URI Description

eggnog://database/stats Cached database statistics from eggNOG 7
eggnog://database/downloads List of all downloadable bulk data files
